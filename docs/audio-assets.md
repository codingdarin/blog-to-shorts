# 음원과 음성

블로그 투 쇼츠는 기본 배경음으로 music.mjs의 자체 합성 라이트 비트를 사용합니다. 기본 음량은 12%, 설정 범위는 0~50%입니다. 전환 효과음은 자체 합성이고 기본적으로 꺼져 있습니다.

원본 local-shorts의 선택형 Pixabay 카탈로그는 코드에 남아 있지만 음원 파일은 복사하지 않았습니다. 사용자가 이용 조건을 확인한 음원을 local-data/music 아래에 배치한 경우에만 목록에 나타납니다. 현재 프로젝트의 검증 결과에는 원본 프로젝트의 행사 영상·음원 사용 기록을 포함하지 않습니다. 원본 기록은 Git 이력에 보존되어 있습니다.

기본 음성은 Windows Microsoft Heami Desktop입니다. 선택형 ElevenLabs는 API 키가 설정된 경우 사용 가능한 음성과 잔여 크레딧을 확인하고, 사용자가 명시적으로 선택한 경우에만 합성합니다. 유료 초과 사용·추가 결제·자동 충전은 하지 않습니다.

이미지·본문·음원의 출처는 UI의 출처 파일 내려받기로 기록합니다. 생성 파일과 음원 원본은 Git 제외 경로에 보관합니다. 실제 검증 상태는 PLAN.md 한 곳에서 관리합니다.
