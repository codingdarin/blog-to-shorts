# 음원과 음성

블로그 투 쇼츠는 사용자 지정 Salsa Estilo New York 03을 기본 배경음으로 사용합니다. 자체 합성 라이트 비트는 제거했습니다. 음원 파일이 없는 환경에서는 브금 없음으로 시작합니다. 기본 음량은 12%, 설정 범위는 0~50%입니다. 전환 효과음은 자체 합성이고 기본적으로 꺼져 있습니다.

원본 local-shorts의 선택형 Pixabay 카탈로그는 코드에 남아 있지만 음원 파일은 복사하지 않았습니다. 사용자가 이용 조건을 확인한 음원을 local-data/music 아래에 배치한 경우에만 목록에 나타납니다. 현재 프로젝트의 검증 결과에는 원본 프로젝트의 행사 영상·음원 사용 기록을 포함하지 않습니다. 원본 기록은 Git 이력에 보존되어 있습니다.

기본 음성은 Windows Microsoft Heami Desktop입니다. 선택형 ElevenLabs는 API 키가 설정된 경우 사용 가능한 음성과 잔여 크레딧을 확인하고, 사용자가 명시적으로 선택한 경우에만 합성합니다. 유료 초과 사용·추가 결제·자동 충전은 하지 않습니다.

이미지·본문·음원의 출처는 UI의 출처 파일 내려받기로 기록합니다. 생성 파일과 음원 원본은 Git 제외 경로에 보관합니다. 실제 검증 상태는 PLAN.md 한 곳에서 관리합니다.

## 추가 곡: Salsa Estilo New York 03

- 사용자 지정 [원곡](https://pixabay.com/music/latin-salsa-estilo-new-york-03-522534/), 제작자 vjgalaxy (Alejandro Piñero Amerio).
- 2026-11-02 페이지에서 Pixabay Content License 무료 사용 표시와 AI generated 표시 확인. Content ID 등록 여부는 페이지에서 확인되지 않아 미확인으로 기록한다.
- 정상 Free download 버튼으로 받은 파일: local-data/music/salsa-new-york.mp3. 미리듣기는 첫 20초를 잘라 salsa-new-york-preview.mp3에 보관한다.
- [라이선스 요약](https://pixabay.com/service/license-summary/)에 따라 새 영상에 편집·혼합해 사용한다. 원곡 파일은 저장소에 넣거나 별도 다운로드 서비스로 제공하지 않는다.
- 앱의 배경음악 선택 목록에 Salsa Estilo New York 03으로 표시한다. 기본 곡으로 사용하며 브금 없음도 선택할 수 있다.
