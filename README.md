# 블로그 투 쇼츠

블로그 본문과 첨부 이미지를 30~60초, 4~6장면의 세로 영상 초안으로 만드는 웹서비스 MVP입니다. 교육 콘텐츠를 기본 톤으로 사용하고 블로그 요약·마케팅 톤도 선택할 수 있습니다.

- 저장소: https://github.com/codingdarin/blog-to-shorts (private)
- 기반 코드: https://github.com/codingdarin/local-shorts 의 `5ca3c00`
- 요구사항·진행·검증: [PLAN.md](PLAN.md)
- 프로젝트 규칙: [AGENTS.md](AGENTS.md), [CLAUDE.md](CLAUDE.md)

## 실행

Node.js 24 이상이 필요합니다. 기본 무료 TTS는 Windows의 Microsoft Heami Desktop 음성을 사용합니다.

```sh
npm ci
# .env.example을 .env로 복사하고 제공받은 API 환경 설정
npm start
```

http://localhost:4311 에 접속합니다. 원본 local-shorts는 4310을 사용하므로 함께 실행할 수 있습니다. 기본 서버는 로컬 주소에만 바인딩합니다.

## 사용 흐름

1. 네이버 블로그 개별 글 URL을 불러오거나 제목·본문을 직접 입력합니다.
2. 수집된 본문과 이미지(최대 8장)를 확인합니다. 이미지를 삭제하거나 내 사진을 추가할 수 있습니다.
3. 교육·블로그·마케팅 톤, 4~6장면, 30·45·60초를 선택합니다.
4. AI가 본문과 실제 이미지를 함께 분석해 Hook → 본문 → CTA 대본과 이미지 매칭을 만듭니다. API 연결 전에는 수동 대본을 작성할 수 있습니다.
5. 장면별 문구(최대 160자)와 이미지를 수정하고 미리보기로 확인합니다.
6. TTS·자막·음악을 합성한 1080×1920 MP4를 미리보고 내려받습니다. SRT 자막과 출처 파일도 저장할 수 있습니다.

교육 자료와 스크린샷의 글자가 잘리지 않도록 이미지를 원래 비율로 배치합니다. 음성 길이가 목표보다 길면 최대 60초 안에서 늘리며, 60초를 넘으면 대본을 줄이도록 안내합니다. 음성을 잘라 목표 길이에 억지로 맞추지 않습니다.

## API 환경

- `NVIDIA_API_KEY` 또는 `GEMINI_API_KEY`: 대본과 이미지 분석. 둘 다 설정하면 NVIDIA를 사용합니다.
- `NVIDIA_MODEL`, `GEMINI_MODEL`: 제공 환경에 맞는 이미지 입력·구조화 출력 지원 모델로 변경할 수 있습니다. 기본값은 원본 프로젝트 설정을 계승했습니다. 실제 제공 계정에서 모델 사용 가능 여부는 별도 확인이 필요합니다.
- `AI_FREE_TIER_CONFIRMED=true`: 무료 사용 범위를 확인한 후에만 설정합니다. 추가 결제·자동 충전은 수행하지 않습니다.
- `ELEVENLABS_API_KEY`: 선택 사항. 사용 가능한 음성과 잔여 크레딧을 조회하고 사용자가 선택한 경우에만 TTS를 요청합니다. 기본은 Windows 무료 음성입니다.
- `PORT=4311`: 원본 앱과 포트를 분리합니다. 키와 원문·이미지·출력 영상은 Git에 올리지 않습니다.

AI 분석에는 768px 이하 JPEG로 변환한 실제 이미지와 본문을 전달합니다. 이미지가 없으면 본문만 분석하며 텍스트 카드로 출력할 수 있습니다. 비용 발생 API를 검증용으로 자동 호출하지 않습니다.

## 수집 범위와 한계

네이버 PC·모바일 개별 글 URL과 PostView 링크를 지원합니다. 모바일 공개 HTML에서 스마트에디터 ONE 및 구형 본문 영역을 읽으며, 네이버 블로그 이미지 호스트만 다운로드합니다. 로그인·비공개·삭제·차단 글은 우회하지 않고 직접 입력 방법을 안내합니다. 본문은 12,000자, HTML은 4MB, 이미지 한 장은 8MB로 제한합니다. 글 구조 변경 시 파서 수정이 필요할 수 있습니다.

현재 작업은 브라우저 메모리에 유지되고 새로고침하면 초기화됩니다. 영상 링크는 서버 메모리에서 최대 3개, 15분간 유지됩니다. 로그인·자동 SNS 게시·작업 내역 저장·AI 이미지 생성·외부 배포는 이번 구현에 포함하지 않았습니다. 공개 배포 전에는 접근 제어, API 사용량 제한과 저장 정책이 필요합니다.
