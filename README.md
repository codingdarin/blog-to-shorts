# 동네컷

지역 뉴스 제목 수집 -> 근거 확인 -> Gemini 대본 생성 -> 4장면 편집 -> 20초 세로 MP4 다운로드.

## 실행

Node.js 24 이상에서 `npm ci`, `npm start` 실행 후 http://localhost:4310 접속.
구문 검증: `npm run check`.

## 무료 AI 연결

`.env.example`을 `.env`로 복사하고 `GEMINI_API_KEY`를 설정한다.
키가 속한 Google AI Studio 프로젝트가 결제 없는 무료 등급임을 확인한 뒤 `AI_FREE_TIER_CONFIRMED=true`로 바꾼다.
서버를 재시작한다. 키는 서버에서만 사용하며 Git에 포함하지 않는다.
무료 한도 초과나 API 오류는 표시하고 자동 재시도/유료 전환하지 않는다.
무료 요금 기준: https://ai.google.dev/gemini-api/docs/pricing

## 시연

1. 지역과 키워드 검색 후 기사 선택.
2. 원문을 열어 확인하고 사용 가능한 근거 텍스트 보충. 수집은 제목/출처/날짜/링크까지이며 전문 크롤링은 하지 않는다.
3. AI로 4장면 생성 후 사실, 행사 종료 여부, 이용 조건을 확인하고 문장 편집.
4. 확인 체크 후 MP4 다운로드. 720 x 1280, 30fps, 20초, 무음.

키 없이 수동 예시로 출력 기능을 검증할 수 있지만 AI 생성으로 표시하지 않는다.
Google News RSS는 가용성이 보장된 공식 뉴스 API가 아니므로 현장 실패 시 직접 자료를 입력한다.
FFmpeg 실행이 필요한 로컬 Node 서버이며 정적 호스팅만으로는 실행되지 않는다.
현재 서버는 127.0.0.1에만 바인딩한다. 외부 공개와 원격 저장소 생성은 미진행.

## 검증 기록

- 2026-10-31: 실제 뉴스 12건 수집, 키 미설정 응답 409 확인.
- 브라우저에서 수동 대본 편집/확인/MP4 다운로드 완료.
- 렌더 API 출력 H.264, 720 x 1280, 20초, 600프레임 디코딩 성공.
- 실제 Gemini 키 연결과 모델 목록 조회(200) 확인. 기존 2.5 Flash 신규 사용자 차단(404)을 확인해 3.8 Flash로 변경.
- 실제 기사 제목으로 생성 요청했으나 공급자 혼잡(503)으로 실패. 3.1 Flash-Lite와 Interactions API도 503. 실제 AI 대본 영상은 아직 미검증이며 배포는 미실행.
