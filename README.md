# 동네컷

지역 뉴스 제목 수집 -> 근거 확인 -> AI 대본 생성 -> 사진과 4장면 편집 -> 한국어 음성 세로 MP4 다운로드.

## 실행

Node.js 24 이상에서 `npm ci`, `npm start` 실행 후 http://localhost:4310 접속.
구문 검증: `npm run check`.

## 무료 AI 연결

`.env.example`을 `.env`로 복사하고 `GEMINI_API_KEY`를 설정한다.
키가 속한 Google AI Studio 프로젝트가 결제 없는 무료 등급임을 확인한 뒤 `AI_FREE_TIER_CONFIRMED=true`로 바꾼다.
서버를 재시작한다. 키는 서버에서만 사용하며 Git에 포함하지 않는다.
NVIDIA Build 무료 키는 `NVIDIA_API_KEY`로 설정한다. 설정되면 Nemotron 3.5 Lightning을 사용하며, 없으면 Gemini 3.8 Flash를 사용한다. 공급자 간 자동 재시도는 없다. NVIDIA 실제 호출 HTTP 200과 검토한 대본의 음성 MP4 다운로드를 검증했다.
무료 한도 초과나 API 오류는 표시하고 자동 재시도/유료 전환하지 않는다.
무료 요금 기준: https://ai.google.dev/gemini-api/docs/pricing

## 시연

1. 지역과 키워드 검색 후 기사 선택.
2. 원문을 열어 확인하고 사용 가능한 근거 텍스트 보충. 수집은 제목/출처/날짜/링크까지이며 전문 크롤링은 하지 않는다.
3. AI로 4장면 생성 후 사실, 행사 종료 여부, 이용 조건을 확인하고 문장 편집.
4. 상단 제목을 쓰고 사용 가능한 사진 1~4장을 선택한다. 적으면 반복 배치한다.
   자동 수집 버튼은 Wikimedia Commons에서 CC0, CC BY 4.0, CC BY-SA 4.0, Public domain 사진만 선택한다. 강남 검색은 역삼 전경과 봉은사 자료사진을 찾는다. 실제 행사 사진으로 표시하지 않는다.
   제목의 `|`는 줄 구분이다. 사진은 중앙 크롭하고 출처/라이선스를 영상에 표시한다. 사진 출처 파일도 함께 내려받아 공유한다. CC BY-SA 사진을 포함한 출력 영상의 공유 조건은 CC BY-SA 4.0이며 앱 소스코드와 별개다.
5. 확인 체크 후 MP4 다운로드. 1080 x 1920이며 음성 길이에 맞춰 장면이 전환된다. 내레이션을 끄면 장면당 5초, 총 20초다.

Windows의 Microsoft Heami Desktop 음성으로 로컬 합성한다. 별도 음성 API 결제가 필요하지 않다. 화면 미리보기는 음성 없는 장면당 5초이며, 다운로드 파일은 실제 음성 길이를 사용한다.

키 없이 수동 예시로 출력 기능을 검증할 수 있지만 AI 생성으로 표시하지 않는다.
Google News RSS는 가용성이 보장된 공식 뉴스 API가 아니므로 현장 실패 시 직접 자료를 입력한다.
FFmpeg 실행이 필요한 로컬 Node 서버이며 정적 호스팅만으로는 실행되지 않는다.
현재 서버는 127.0.0.1에만 바인딩한다. 외부 공개와 원격 저장소 생성은 미진행.

## 검증 기록

- 2026-10-31: 실제 뉴스 12건 수집, 키 미설정 응답 409 확인.
- 브라우저에서 수동 대본 편집/확인/MP4 다운로드 완료.
- 렌더 API 출력 H.264, 720 x 1280, 20초, 600프레임 디코딩 성공.
- 실제 Gemini 키 연결과 모델 목록 조회(200) 확인. 기존 2.5 Flash 신규 사용자 차단(404)을 확인해 3.8 Flash로 변경.
- 실제 기사 제목으로 생성 요청했으나 공급자 혼잡(503)으로 실패. 3.1 Flash-Lite와 Interactions API도 503. 실제 AI 대본 영상은 아직 미검증이며 배포는 미실행.
- 레퍼런스 반영: 검정 배경, 흰색/노랑 고정 제목, 가운데 사진, 하단 자막. 제공 영상의 사진은 앱 자산으로 복제하지 않았다.
- 로컬 한국어 합성 테스트: 1080 x 1920 H.264 + 48kHz AAC, 12.47초, 디코딩 종료 코드 0. 사진 파일 업로드 전체 흐름은 아직 미검증이다.

- NVIDIA 후속 검증: 실제 기사 제목으로 AI 생성 성공. 초안에 근거 없는 문장이 있어 사람이 수정 후 내레이션 MP4 다운로드. 1080 x 1920, AAC, 16.36초, 디코딩 성공. 테스트 이미지 업로드도 확인했다. 실제 행사 사진은 미포함.

## 사진 포함 완성본

- `local-data/deliverables/gangnam-news-short.mp4`: 자동 수집한 강남 지역 자료사진 4장, 검토한 AI 대본, 로컬 한국어 내레이션. 1080 x 1920, 18.86초, 2,373,931 bytes. 전체 영상/음성 디코딩 종료 코드 0.
- `local-data/deliverables/gangnam-news-short-credits.md`: 작가, 원본, 촬영일, 라이선스와 기사 근거. 기사 당일 현장 사진은 아니다.
- 실제 사진 자동 수집, 캔버스 합성, 브라우저 MP4 및 출처 파일 다운로드를 검증했다. 외부 배포는 미실행.
- NVIDIA JSON 응답 형식 오류를 관찰해 공식 JSON 출력 모드를 추가하고 실제 재생성 성공을 확인했다.
- ElevenLabs 계정의 10,000 잔여 크레딧은 확인했지만 생성에 사용하지 않았다. 무료 플랜은 비상업용이며 공개 시 제목 출처 표시가 필요하다: https://help.elevenlabs.io/hc/en-us/articles/13313564601361-Can-I-publish-the-content-I-generate-on-the-platform
